# Портфолио дизайнера костюма

Статический одностраничный сайт без сборки и зависимостей: HTML, CSS и vanilla JavaScript.

## Как запустить

Можно открыть `index.html` напрямую или запустить локальный сервер:

```bash
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

## Как менять контент

Весь текст, контакты, ссылки и проекты находятся в `content.js`.

- Замените ФИО, образование, почту и текст «О себе» в объекте `profile`.
- Все абзацы раздела «О себе» используют одинаковую основную типографику.
- Замените `assets/images/designer-portrait.webp` на настоящее фото дизайнера, сохранив имя файла, либо измените путь в поле `profile.portrait`.
- Чтобы добавить проект, скопируйте один объект внутри массива `posts` и укажите категорию, дату, описание и массив фотографий.
- Категории в панели фильтров создаются автоматически из поля `category`.
- На главной показываются до трёх фотографий проекта. Необязательное поле `previewCount: 1`, `2` или `3` задаёт их количество вручную.
- Если `previewCount` отсутствует и первый кадр широкий, на главной автоматически остаётся только он. Галерея использует реальные пропорции изображений.
- Одиночный широкий кадр ограничивается высотой экрана и полностью помещается как на компьютере, так и при горизонтальном повороте телефона.
- На узком экране несколько фотографий остаются горизонтальным рядом с прокруткой.
- Полноэкранный просмотр поддерживает миниатюры, масштаб от 50% до 300%, кнопки `− / +`, двойной клик и клавиши-стрелки.
- Для GitHub Pages и Vercel используются относительные пути, дополнительная настройка не нужна.

Социальные ссылки в демонстрационной версии ведут на главные страницы сервисов — замените их в массиве `socials`.
